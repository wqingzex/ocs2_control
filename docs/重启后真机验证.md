# 重启后真机验证

按顺序做。每一步给出操作和过关标准，不过关就停在这一步。除第 1 节外，命令都在容器 shell 里执行。

## 1. 宿主机检查

在桌面终端里执行。

| # | 命令 | 过关标准 |
|---|---|---|
| 1 | `systemctl is-active docker` | `active` |
| 2 | `ip -br link show can0` | 有 `can0` |
| 3 | `ping -c 2 192.168.1.190` | 0% 丢包 |
| 4 | `ls /dev/serial/by-id/` | 两行，含 `A9BJTL0I`（左）和 `AF7IE1RC`（右） |
| 5 | `lsusb \| grep -ci 2bc5` | `3` |
| 6 | `echo $DISPLAY` | 有值 |
| 7 | 机械臂控制器、腰和头电机、手上电 | 已上电 |

## 2. 进入容器

```bash
cd /home/fiveages/tmp/ocs2_control
./docker/run.sh
```

每开一个新终端，重新执行 `./docker/run.sh`。

```bash
test -f /.dockerenv && echo "在容器里" || echo "在宿主机上"
xeyes
sudo -n true && echo sudo-ok
ls /opt/apps/roboticsservice/runService.sh
grep MARVIN_FIRMWARE: build/marvin_hardware/CMakeCache.txt
```

过关标准：`在容器里`；`xeyes` 弹出窗口（Ctrl+C 关闭）；`sudo-ok`；`runService.sh` 存在；固件是 `MARVIN_FIRMWARE:STRING=338`。

## 3. setup.sh

### 3.1 查看配置

```bash
./scripts/start.sh check
```

过关标准：显示运控启动命令（`whole_body.launch.py`、`type:=linkerhand_l6`）和三台相机序列号。

### 3.2 相机

```bash
./scripts/setup.sh cam
```

1. 遮住左腕镜头，对应卡片画面变黑；再遮右腕。位置与实物不一致，点"交换左右腕"。
2. 调"画面旋转"到方向正确，点"应用配置并预览"。
3. 三张卡片都勾"我已核对该画面的位置和方向"，点"确认并保存"。

过关标准：终端出现 `>>> 相机画面与位置已确认`，配置里每台相机有 `rotation`。

### 3.3 灵巧手

手周围无遮挡。

```bash
./scripts/setup.sh hand
```

1. 左手卡片点"开合测试"，确认动的是机器人的左手。
2. 右手同样。
3. 两张卡片都勾"我已核对该设备是机器人的左手/右手"，点"确认并保存"。

过关标准：终端出现 `>>> 左右手配置已确认`。手不应答时，给手断电 10 秒再上电后重试。

### 3.4 头显配对

```bash
./scripts/setup.sh xr
```

1. 选网线，网卡选 `enx6c1ff7b8c773`（只有一块时自动选）。
2. 头显 App（XRoboToolkit）选终端打印的 PC Service 地址，Tracking 勾 Head 或 Controller，开启 Data & Control 的 Send。
3. 收到追踪数据后，按提示输入 `y` 绑定。

过关标准：`config/robot.local.yaml` 的 `xr.device_id` 有值。

### 3.5 最终检查

```bash
./scripts/setup.sh check
```

过关标准：三台相机带 `旋转`；两只手的串口是 `/dev/serial/by-id/…`；`相机画面与位置`、`左右手实物` 都是 `已确认`。

## 4. 启动并验证（手臂不动）

### 4.1 相机

```bash
./scripts/start.sh up camera_head camera_left_wrist camera_right_wrist
./scripts/start.sh status --hz
```

过关标准：三个模块"运行"；约 60 秒后三台 `compressed` 都是 30 Hz。

### 4.2 运控

急停在手边，手臂周围无人。先探测手：

```bash
python3 -m w2_hand.hand <<< '{"side":"left","operation":"probe","hand":"linkerhand_l6","drive":"usb","port":"/dev/serial/by-id/usb-FTDI_FT232R_USB_UART_A9BJTL0I-if00-port0"}' | grep W2_HAND_RESULT
python3 -m w2_hand.hand <<< '{"side":"right","operation":"probe","hand":"linkerhand_l6","drive":"usb","port":"/dev/serial/by-id/usb-FTDI_FT232R_USB_UART_AF7IE1RC-if00-port0"}' | grep W2_HAND_RESULT
```

过关标准：两行都是 `"ok": true`。不是则给那只手断电 10 秒再上电。

```bash
./scripts/start.sh up control
./scripts/start.sh status --hz
```

过关标准：输出 `>>> 运控就绪：控制器全部激活`，听到臂上电声，RViz 打开，`status` 里运控 `FSM=HOLD`。

```bash
ros2 service call /controller_manager/list_controllers controller_manager_msgs/srv/ListControllers 2>&1 | grep -oE "name='[a-z_]+'|state='[a-z]+'" | paste - -
ros2 topic echo /fsm_state --once 2>/dev/null | grep ^data
grep -n "HW-00\|\[ERROR\]" logs/control/latest.log | grep -v "zenoh\|pal_statistics"
./scripts/nudge.py show
```

过关标准：
- 4 个控制器全部 `active`：`whole_body_controller`、`left_hand_controller`、`right_hand_controller`、`joint_state_broadcaster`；
- `data: 2`；
- 第三条没有 `HW-00x`；`[ERROR]` 只允许启动时左右手各一条 `Failed to read L6 hand position`；
- `nudge.py show` 的头和腰 6 个关节有数值，手臂没有动作。

### 4.3 灵巧手

手周围无遮挡。

```bash
./scripts/nudge.py fsm movej
grep -c "Failed to read L6 hand position\|Failed to write" logs/control/latest.log
ros2 topic pub --once /left_hand_controller/target_percent std_msgs/msg/Float64 "{data: 0.5}"
ros2 topic pub --once /left_hand_controller/target_command std_msgs/msg/Int32 "{data: 1}"
ros2 topic pub --once /left_hand_controller/target_command std_msgs/msg/Int32 "{data: 0}"
```

每条等 3 秒观察。右手把 `left_hand_controller` 换成 `right_hand_controller` 重复，最后再数一次超时计数。

过关标准：`fsm_state: 4` 且没有运动；手指按命令开合，`0.5` 在张开和闭合之间，左右手各自响应；超时计数没有增长。

### 4.4 头和腰

状态机在 MOVEJ。每条等它打印"到位"再做下一条：

```bash
./scripts/nudge.py head 1 0.05
./scripts/nudge.py head 1 -0.05
./scripts/nudge.py head 2 0.05
./scripts/nudge.py head 2 -0.05
./scripts/nudge.py waist 0.05
./scripts/nudge.py waist -0.05
./scripts/nudge.py fsm hold
```

过关标准：每条都打印 `到位`（静差不超过 0.003 rad），回位后回到原值；最后 `fsm_state: 2`。不要试腰的升降、位姿、`body_joint1~3`，不要让头大幅运动。

### 4.5 停止运控

```bash
./scripts/start.sh down control
ps -eo pid,args | grep -E "ros2_control_node|whole_body.launch|rviz2" | grep -v grep
```

过关标准：`down` 完成；日志最后是 `process has finished cleanly`、`Robot released`；`ps` 没有输出。

再次启动运控前，重新做 4.2 开头的手探测。

## 5. 遥操作

手臂在这里第一次跟随，不过关立即 LB+B 或急停。

### 5.A 手柄

先确认手柄被识别：`ros2 run joy joy_enumerate_devices`。

```bash
./scripts/start.sh up control
./scripts/start.sh up joystick
```

| 按键 | 作用 |
|---|---|
| 右摇杆按下 | 启用 / 停用手柄 |
| LB+B | 回 HOLD |
| LB+Y | HOLD → MOVEJ |
| LB+START | HOLD → OCS2 |
| A | 切换左 / 右臂 |
| RB | 切换手臂 / 底盘模式 |
| 左摇杆按下 | 高速 / 低速 |
| Back | 镜像开关 |

不要按 LB+A（HOME）。

操作：右摇杆启用，LB+START 进 OCS2，小幅推摇杆。

过关标准：手臂按摇杆方向小幅跟随，幅度合理；LB+B 后回 HOLD，手臂停住。

### 5.B 头显

```bash
./scripts/start.sh up control
./scripts/start.sh up xr
ros2 topic echo /teleop/connection_status --once 2>/dev/null | grep ^data
```

操作（legacy 方案，默认）：

| 按键 | 当前状态 → 结果 |
|---|---|
| 右 A | HOLD → OCS2；HOME → HOLD；已在 OCS2 时无效 |
| 左 X | OCS2 → HOLD；MOVEJ → HOLD；**HOLD → HOME**；HOME 里切 HOME ↔ REST |
| 右摇杆单击 | STORAGE ↔ UPDATE（OCS2 下才会让手臂跟随） |

流程：右 A 进 OCS2，右摇杆单击进 UPDATE，小幅移动；结束时右摇杆单击回 STORAGE，**左 X 按一次**回 HOLD。左 X 只按一次，在 HOLD 里再按会进 HOME。simple 方案的按键见 [`VR遥操作.md`](VR遥操作.md) 第 5 节。

过关标准：跟随时整条手臂不上下晃；`up xr` 输出 `>>> 头显已连接，正在接收追踪数据`（头显没连上时输出 `[警告]` 和缺什么，先在头显 App 里连上）；`data: true`；手臂按头显手柄的动作小幅跟随，方向和幅度合理；左 X 一次后 `fsm_state` 是 `data: 2`。

## 6. 收尾

```bash
./scripts/start.sh down
ps -eo pid,args | grep -E "ros2_control_node|whole_body.launch|rviz2" | grep -v grep
exit
```

过关标准：`down` 完成，`ps` 没有输出。
