正面键：命令（按下即生效）
右 A状态机前进：HOME → HOLD → OCS2（进入 OCS2 后手臂待命，还不跟随）；已在 OCS2 无效
左 X状态机后退：OCS2 / MOVEJ → HOLD；HOLD 下再按 → HOME（手臂会动）；HOME 下切换 HOME ↔ REST。退出 OCS2 只按一次

背面键：操作
左 / 右 扳机对应的手 / 夹爪按比例开合：松开张开，按到底闭合
