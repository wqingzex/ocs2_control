按键作用
右 AHOLD → OCS2（手臂待命，还不跟随）；HOME 下回 HOLD；已在 OCS2 无效
右摇杆 单击STORAGE ↔ UPDATE：进入 UPDATE 后手臂跟随手柄，再单击停止跟随（需要先在 OCS2）
左 XOCS2 / MOVEJ → HOLD；HOLD 下再按 → HOME（手臂会动）；HOME 下切换 HOME ↔ REST。退出 OCS2 只按一次
左 / 右 扳机对应的手按比例开合
左 Y + 右 B扳机在"按比例 / 开关"两种模式间切换
左 / 右 握把 单击切换该臂摇杆模式：XY 平移 ↔ Z 升降 + 偏航
左摇杆 单击镜像开关
左 Y / 右 B 单击暂停 / 恢复
按键作用
右 AHOLD ↔ OCS2
左 XHOME / HOLD（HOLD 下 → HOME，手臂会动）
左 / 右 握把 按住对应手臂跟随，松开即停；按下时重新记录基准（进入 OCS2 时已经按着的要先松开再按）
左 / 右 扳机对应的手按比例开合
左 Y + 右 A进入 MOVEJ
右 B 单按 / 左 Y 长按 0.8 秒录制开始 / 停止；删除上一条录制
